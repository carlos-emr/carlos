# `bc/` — British Columbia migrations

`V1__baseline_schema.sql` is the British Columbia schema baseline (structure only), generated by
`database/mysql/build-baseline.sh` from `createdatabase_generic.sh bc 9` + the required updates.

Applied together with `common/` for a BC install (`flyway.locations=...common,...bc`). New BC schema
changes go here as `VYYYY.MM.DD[.N]__short_description.sql`.
