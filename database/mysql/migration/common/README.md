# `common/` — shared migrations

`V1__baseline_schema.sql` is the province-neutral schema baseline (structure only) — the tables
identical across Ontario and BC. Generated by `database/mysql/build-baseline.sh`.

Applied together with the selected province (`common` + `on`, or `common` + `bc`). Put **genuinely
shared future schema changes** here as `VYYYY.MM.DD[.N]__short_description.sql` so one migration
covers both provinces.
