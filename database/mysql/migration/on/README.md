# `on/` — Ontario migrations

`V1__baseline_schema.sql` is the Ontario schema baseline (structure only), generated by
`database/mysql/build-baseline.sh` from `createdatabase_generic.sh on 9` + the required updates.

Applied together with `common/` for an Ontario install (`flyway.locations=...common,...on`). New
Ontario schema changes go here as `VYYYY.MM.DD[.N]__short_description.sql`.
