# CARLOS Patient Portal Mocks

Open `index.html` in a browser to view the sign-in screen.

Other screens can be opened with `?screen=`:

- `index.html?screen=signin-error`
- `index.html?screen=activate`
- `index.html?screen=reset`
- `index.html?screen=mfa`
- `index.html?screen=mfa-error`
- `index.html?screen=locked`
- `index.html?screen=dashboard`
- `index.html?screen=passwords`
- `index.html?screen=passwords-empty`
- `index.html?screen=account`
- `index.html?screen=staff`
- `index.html?screen=messages`

Included screens:

1. Sign in
2. Sign in error
3. Portal account activation
4. Password reset
5. MFA
6. MFA error
7. Locked account
8. Patient dashboard
9. Email passwords
10. Empty email passwords
11. Account settings
12. CARLOS staff invite/admin view
13. Future patient messages concept

The mock takes visual cues from CARLOS/OSCAR: compact layout, blue selected states, light grey toolbars, table-like rows, small controls, and existing CARLOS/OSCAR logo assets.

Saved screenshots are in `screenshots/`. Each included screen has desktop and mobile screenshots.
