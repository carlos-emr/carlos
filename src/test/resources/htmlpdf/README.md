# HTML-to-PDF test fixtures

Documents for the tests of `io.github.carlos_emr.carlos.documentManager.htmlpdf` (see
`docs/superpowers/specs/2026-10-29-flying-saucer-html-pdf-consolidation-design.md`, "Testing").
Every name in them starts with `FAKE-`; none is real patient data.

| Folder | What | How it was made |
|---|---|---|
| `annual/` | The Annual Health Review, female and male, as the server renders a saved form: ticked boxes, field values, two-line text areas, the hidden fields, the row spans | Derived from `src/main/webapp/WEB-INF/jsp/form/formannual{female,male}.jsp` by `scripts/htmlpdf/derive-annual-fixtures.py`. `scripts/htmlpdf/capture-annual-fixtures.js` captures them from a running devcontainer instead. The tests copy the application's own `form/annualStyle.css` and `form/print.css` next to them at run time |
| `forms/` | One page with every control type (CJK and Hebrew values, `optgroup`, `progress`, `meter`, hidden fields that must never print) | By hand |
| `hrm/` | A hospital discharge summary as HTML, a table-heavy report, a report that began as a Word document (`windowtext` borders, `<o:p>`, comments with `--`), and a report with every kind of image | By hand. `images.html` names image files the test writes into the folder (TestImages), so no binary is committed except `images/` below |
| `email/`, `messenger/` | An encrypted-email message body, a Messenger letter | By hand |
| `geometry/` | Pages of 400, 850, 1000 and 1400 px, a narrow page followed by a wide one, an author `@page`, small text, print and screen media rules, a long URL, a table across pages, `position: fixed`, soft hyphens, `<ol type>`, an over-long `rowspan` | By hand |
| `scripts/` | Latin accents, CJK, symbols, Hebrew (short and long), Arabic, Urdu, Hindi, Punjabi, Tamil, Thai, Vietnamese | By hand |
| `edge/` | Empty elements, self-closing tags, misnested tags, entities, a fragment, plain text | By hand |
| `images/` | Two small binaries: a JPEG with EXIF orientation 6 and a 4x4 WebP (a format that is deliberately not decoded) | Task 3 |

The 2000-row table, the 48-megapixel JPEG, the 67-megapixel PNG and the header that declares 20 000 x 20 000
pixels are generated by the tests at run time into a temporary directory.

No document "crafted to fail layout" is kept: fifteen exotic documents (500 nested divs, 450 nested tables, 3000
floats, a 100 000 px block, a 9 999 999 px width, `font-size: 99999px`, ...) all lay out in Flying Saucer 10.7.0,
so the fallback ladder is tested with forced failures (Mockito spies) instead.
