## Decoder behavior and bounded recovery

This local Qwen/Ollama combination did not emit a stop token after its first
complete JSON object. Depending on the prompt, it appended commentary, repeated
the object, or emitted structure-only debris until reaching the output limit.
The harness now permits a compatibility path only for fluent mode: on
`done_reason=length`, it parses the first complete JSON value and ignores all
later bytes. It never interprets the suffix. The parsed value must still pass the
strict field shape, duplicate-key, exact-quotation, numeric, lexical, section,
coverage, citation, and labelled-fact checks. Raw responses remain preserved and
each final row records `structured_prefix_recovered: true`.

This is an operational workaround, not evidence that the model follows the JSON
termination instruction. A future Ollama or model update should be retested to
remove the recovery path if normal stopping becomes reliable.

## Decision

The fluent delta has merit for readability and retains the normalized delta's
stronger evidence boundary on these invented cases. It is the preferred synthetic
27B candidate for further review. The case set is small, every final row required
the bounded decoder recovery, and no clinician has evaluated the prose; therefore
this result is not sufficient for production promotion or a clinical-safety claim.
